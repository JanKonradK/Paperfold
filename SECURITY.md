# Security policy

## Supported versions

Only the latest Paperfold release receives security fixes.
Earlier releases do not receive security fixes.

## Report a security problem

Use [GitHub private vulnerability reporting](https://github.com/JanKonradK/Paperfold/security/advisories/new).
Do not open a public issue for a security problem.

Include these details:

- The Paperfold version and build number.
- The device and operating system version.
- Steps to reproduce the problem.
- The possible effect of the problem.
- A small example or logs, if available.

Remove personal data, passwords, and access tokens from the report.
Use example files that you have permission to share.

Paperfold is a volunteer project.
Maintainers review reports and respond on a best-effort basis.
The project does not promise a fixed response time or a fixed date for a security fix.

## Anx Reader upstream

Paperfold is a fork of [Anx Reader](https://github.com/Anxcye/anx-reader).
For security problems in Anx Reader, use the upstream project's private security channel.
Do not open a public issue for an upstream security problem.
